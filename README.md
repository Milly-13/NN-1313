# NN-1313

Интерактивный проект для обучения финансовой грамотности детей 7–11 лет. В основе — простые задания и примеры о деньгах, реализованные на HTML, CSS и JavaScript.

## Стек технологий
- HTML5
- CSS3
- JavaScript

## Как запустить локально
1. Скачай или клонируй репозиторий.
2. Открой файл `index.html` в любом браузере.
